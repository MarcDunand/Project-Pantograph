If nothing arrives

  1. In iDraw OSC on the iPad, set the IP to … and the port to 8800.
  2. The iPad and this computer are on the same Wi-Fi network.
  3. Windows: the Wi-Fi network is set to Private, not Public. Settings → Network & internet → Wi-Fi → your network → Network profile type → Private.
  4. When Windows asked about the firewall, you chose Allow. If you cancelled it: open “Allow an app through Windows Firewall”, press Change settings, and tick Private for python.exe.The Mac firewall is off by default. If you turned it on: System Settings → Network → Firewall → Options, and allow Python.
  5. Nothing else is using port 8800. If the status says the port is busy, pick another port above and set the same one in iDraw.
  6. Some school, work, hotel and guest networks stop devices from reaching each other. A phone hotspot is a quick test. The fix is a different network, or Tailscale (see the README).
  7. Press Restart listener, then draw a stroke. The dot turns green when it arrives.

Plotter

Walk Home, Set Home and Disengage XY Motors are in the plotter controller.

If the plotter isn't found

  1. The USB cable is plugged in, and the AxiDraw's own power supply is on. USB alone doesn't power the motors.
  2. Try another USB port or cable. Some cables only charge.
  3. Close other programs using the AxiDraw: Inkscape's AxiDraw extension, or a second Pantograph.
  4. pyaxidraw is installed. If it isn't, the status says “No pyaxidraw”.
  5. Press Connect, and read the message above if it fails.
  6. Try the pen tests in the plotter controller.
